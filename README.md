# IRIS — Enterprise Multi-Agent Operating System

IRIS turns a startup task into a CEO-led operating workflow: the CEO defines a
plan, specialist agents work in parallel, and an independent reviewer checks
the combined delivery. Every run has a persisted strategy, output, cost
estimate, and execution trace.

## Run

Requires Python 3.11+. Install the OpenAI SDK used for NVIDIA NIM:

```powershell
uv pip install -r requirements.txt
uv run --python 3.11 python run.py
```

Open `http://127.0.0.1:8000`. The SQLite database is created at `data/iris.db`.

## NVIDIA NIM setup

Set an NVIDIA API key before starting IRIS to use real LLM calls:

```powershell
$env:NVIDIA_API_KEY = "nvapi-..."
$env:NIM_MODEL = "nvidia/nemotron-3.5-lightning-30b-a3b" # optional
uv run --python 3.11 python run.py
```

IRIS uses the OpenAI Python SDK against NVIDIA NIM's OpenAI-compatible
`POST /v1/chat/completions` endpoint, with streaming and NVIDIA reasoning
enabled. Each role can use a separate `NVIDIA_API_KEY_<ROLE>` so access, usage,
and rate limits can be isolated; see `.env.example`. For a self-hosted NIM,
configure `NIM_BASE_URL` with its `/v1` URL. If no key is present or the SDK is
not installed, IRIS produces safe local simulated outputs. Set
`IRIS_RUNTIME=simulated` to force local mode.

## Features

- **Claude Co-Work Autonomous Squad**: Collaborative workspace where the CEO plans, specialists (Full-Stack Architect, Developer, Tester, HR, Resource) deliver in parallel, and an independent Reviewer audits delivery.
- **Real Workspace File System (`workspace/`)**: All files generated by agents (websites, HTML5, CSS, JS, Python scripts) are written directly into `workspace/`. Built-in live browser iframe preview at `/workspace/index.html` and code inspector.
- **Deterministic Agent Firewall**: Strict domain boundary enforcement. If you ask an agent to perform work outside its scope (e.g. asking the HR Agent to develop a website or write code), the firewall immediately intercepts the execution, blocks it, and redirects you to the proper specialist (Developer Agent or Full-Stack Architect).
- **Dedicated 1-on-1 Agent Desks**: Separate interactive pages for all 7 specialist agents with role mandates, boundary cards, live reliability/cost metrics, and instant firewall testing scenarios.
- **Persistent Organizational Memory**: Automatically stores lessons learned and strategies across runs. Allows users to teach custom company rules and injects memories into new tasks based on keyword matching.
- **Professional Startup Dashboard**: High-polish dark mode UI with glassmorphism, responsive navigation tabs (Co-Work Squad, Workspace Files, Agent Desks, Memory Bank, Analytics, System Settings).

## Startup Squad

- **CEO Agent (👑)** — Scope, priorities, acceptance criteria, and risk ownership.
- **Full-Stack Architect (🏗️)** — System and component architecture, integration schemas.
- **Developer Agent (💻)** — Production code implementation, websites, scripts, and handoff.
- **Testing Agent (🧪)** — Test strategy, edge case assertions, and QA verification evidence.
- **Review Agent (🛡️)** — Independent security auditing and delivery sign-off gate.
- **Resource Agent (📦)** — Dependencies, external references, and technical research.
- **HR Agent (🤝)** — People operations, hiring criteria, team structure, and organizational policy.

## API Endpoints

- `POST /api/tasks` — Launch a full startup squad co-work task.
- `GET /api/dashboard` — Summary KPIs, completed tasks, success rate, and memory counts.
- `GET /api/workspace` — List all files generated in `workspace/`.
- `GET /api/workspace/file?name=...` — Read raw file contents.
- `POST /api/workspace/file` — Create or update workspace file.
- `GET /workspace/{filename}` — Direct static serving with live preview.
- `GET /api/agents` — List all 7 specialist agents with firewall rules.
- `POST /api/agents/{id}/chat` — 1-on-1 prompt to specific agent with strict firewall validation.
- `GET /api/memories` — Retrieve persistent organizational memories.
- `POST /api/memories` — Teach custom organizational rules to the long-term memory bank.
- `GET /api/system` — System status, NVIDIA NIM connection state, and active model.
